# NexusOS — Autonomous Agentic AI Operating System

## Project Overview
NexusOS is a custom Linux distribution based on Linux Mint that embeds autonomous AI agents
directly at the OS level. Unlike traditional AI assistants that suggest actions, NexusOS agents
**execute** — making complex business decisions and taking action independently.

The platform ("Nexus Core") serves as a decentralized operating system for businesses where
Agentic units replace middle management, proactively managing entire business verticals.

## Architecture

### Core Components
- **nexus-core**: Python agent orchestration engine (systemd daemon)
- **nexus-directory**: Native LDAP-compatible identity provider (AD/Entra hybrid)
- **nexus-mcp-bridge**: Model Context Protocol integration layer
- **overlay/**: Files overlaid onto the Linux Mint base during ISO build

### Key Design Decisions
- **Base**: Linux Mint (Ubuntu LTS-based, stable, familiar desktop)
- **Agent Protocol**: MCP (Model Context Protocol) — 2026 industry standard
- **Identity**: Unified human + agent identities; compatible with Microsoft Entra ID
- **Scheduler**: SCX_rusty kernel scheduler for AI workload prioritization
- **Pricing**: Digital Labor Credits (credit-based consumption model)

### Identity Model
Every entity (human or agent) gets a single NexusIdentity that follows them across devices.
Supports three modes: `nexus` (native), `entra` (Microsoft AD), `hybrid` (both synced).


## Directory Structure
```
NexusOS/
├── build.sh              # ISO build script
├── config/               # Default configuration files
│   ├── nexus.conf        # Main system config (TOML)
│   └── mcp-registry.json # MCP server registry
├── src/
│   ├── nexus-core/       # Agent orchestration engine
│   └── nexus-directory/  # Native directory service
├── overlay/              # Files overlaid onto base ISO
│   └── etc/
│       ├── systemd/system/  # Service files
│       └── nexus/           # Runtime config
├── tests/                # pytest test suite
└── docs/                 # Documentation & business plan
```

## Conventions
- Python 3.11+ with asyncio, type hints, dataclasses
- TOML for configuration, JSON for registries/schemas
- All agents run sandboxed by default
- Every agent action is logged with confidence score + explainability link
- Credit consumption tracked per-agent in local SQLite ledger
